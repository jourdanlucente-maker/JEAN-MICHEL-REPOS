## How to Contribute

We welcome contributions from vibe coders who:

## Contribution Ideas

1. **New REST Activities**: Suggest wellness activities to recommend during mandatory REST
2. **Integration Plugins**: Build integrations with popular AI tools (VS Code, GitHub Copilot, etc.)
3. **Analytics**: Help us understand vibe coding patterns
4. **Documentation**: Share your story of vibe coding addiction and recovery
5. **Tests**: Write tests for the token counter and wellness monitor

## Code of Conduct

- **Respect REST**: Don't shame people for taking breaks; celebrate them.
- **Honest metrics**: Report truthfully on your token usage.
- **Wellness first**: If a feature conflicts with wellness, choose wellness.

## Submission Process

1. Fork the repo
2. Create a feature branch: `git checkout -b feature/your-idea`
3. Make your changes
4. Commit with a clear message
5. Push to your fork
6. Open a Pull Request with:
   - Clear title and description
   - Link to any relevant issues
   - Evidence that you've tested it (and taken REST)
