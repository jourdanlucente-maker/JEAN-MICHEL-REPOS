# 🧘 JEAN-MICHEL-REPOS

**Real REST for Vibe Coders** – Because you've been iterating for too long.

---

## The Problem

You're in the flow. The code is vibing. The tokens are flowing. Three million tokens later, you realize you haven't taken a break, eaten, or stepped outside. Welcome to **vibe coding addiction**—it's more addictive than vape. It's basically vape coding at this point.

## The Solution

**JEAN-MICHEL-REPOS** is your digital wellness companion. It's a system that watches your token consumption and gently (or firmly) tells you: **STOP. Take a break. Touch grass.**

---

## Core Philosophy

- **3M Token Limit**: After 3 million tokens of iteration, the system enforces a REST protocol.
- **Wellness First**: Real rest, not API rest. Sleep. Breathe. Hydrate.
- **For Vibe Coders**: Built by those who understand the addiction. Built with empathy.

---

## Features

- 🚨 **Token Counter**: Tracks your iteration depth
- 🛑 **3M Token Brake**: Hard stop at the threshold
- 💤 **REST Protocol**: Enforces breaks
- 📊 **Vibe Analytics**: Monitor your coding patterns
- 🎯 **Skill Integration**: Works with your AI tools

---

## Getting Started

```bash
# Clone the repo
git clone https://github.com/jourdanlucente-maker/JEAN-MICHEL-REPOS.git
cd JEAN-MICHEL-REPOS

# Install dependencies
npm install

# Start the wellness monitor
npm run rest
```

## The Idea Repos 💡

Each Jean Michel idea lives as its own standalone repo-shaped project
(one folder = one future repo, each with its own README, LICENSE and the
contribution link):

- ⏰ [**open-clowk**](open-clowk) — the desktop mascot. After N minutes
  without a pause (90 by default, you decide), the orange pixel robot walks
  onto your screen and opens every clock. `npm run demo` to see it now.
  Plus the chaotic CLI (`open-clowk --all`). Tic tac, MF.
- 👜 [**agent-hermes-bag**](agent-hermes-bag) — the agent that insists.
  Ask it if your bag is on the way (EN/FR/ES), then send its funding
  message via Gmail, Outlook, WhatsApp or Instagram. Just open
  `agent-hermes-bag/index.html`.

Jean Michel makes you rest. Open Clowk makes you forget. Balance.
